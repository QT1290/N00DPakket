E-mailherinneringen

Optioneel. De app bewaart een versleutelde kopie van je lijst in je GitHub-repository. Eén keer per week kijkt GitHub of er iets bijna verloopt en stuurt je dan een e-mail, zonder namen van items. Zonder jouw wachtwoord kan niemand de kopie lezen. Zie de README voor de stappen.
